# 原生曲线、构图参考与动画检查

适用于需要精修方法图、反馈回路或分步讲解的演示文稿；简单文字修订无需执行整套流程。

## 构图参考到可编辑图

- 代表页可覆盖总览、研究问题、特征流、受控比较、决策循环等不同叙事角色，避免只给封面生图。覆盖数量遵循用户要求与改动范围。
- 建立对应清单：页码／叙事目的／生成提示／参考图／原生重绘预览。准确记录实际可确认的生成工具或模型；不猜测后台版本。
- 图像提供构图灵感。新增的模型、公式、数据、比较结论需重新核对，不能直接变成研究内容。示意曲线与教学构造明确标注。
- 重绘时保留文本、形状、路径与图表的编辑性。按需要附参考—重绘对照，用户才能看到参考实际用于哪些页面。

## 曲线与对齐

- 优先使用 PowerPoint 原生自由曲线或自定义 Bézier 路径（例如 OOXML `a:cubicBezTo`）。圆滑转折用于表达方向，端点落在模块可见边界，避免用大量细小线段拼接圆角。
- 区分原生连接器与自定义路径：路径通常不会随节点自动吸附。节点移动后重新计算路径，或将完整语义单元组合后整体移动；不要承诺自动跟随。
- 箭头方向与末段切线一致，线头不穿进文字。箭头头部若为独立形状，应与路径一起分组，缩放后复查接缝。
- 原生曲线不适用时，可导入真正的矢量 SVG；保持视口、宽高比与内部坐标一致。清楚区分“可缩放 SVG 图片”与“可分别编辑节点的原生对象”，嵌入 SVG 不等于每个部件可编辑。
- 不把整张位图封装为 SVG 后称作矢量化。原生和 SVG 混用时统一定位容器与缩放比例，检查连接端点，避免各组件独立缩放导致错位。

## 按讲解阶段组织动画

先写阶段清单，再添加效果。每个阶段包含模块背景、文字、内部图、进入该模块的连线和箭头；来源已显示、目标本次出现，才展示对应连接。反馈循环在反馈与状态更新之后闭合，停止分支在决策条件之后显示。

例：初始任务 → 排序及入线 → 执行及入线 → 结果反馈及入线 → 状态更新与判定 → 继续／停止分支。这是循环图的示例，不是所有页面的固定模板。

- 使用稳定形状名称，记录分组后实际组名；动画绑定整个阶段，防止文字先出现、框后出现。
- 用户未指定时选择简洁的淡入或出现。点击次数按讲解需求安排；密集表格和对照不必逐个单元格播放。
- 在初始状态保留定位信息；后续阶段不得留下指向尚未显示对象的悬空线条。比较结果出现时保留相应基线。

## 检查真实呈现

1. 用目标 PowerPoint 导出静态页，检查全内容布局与字体。
2. 对有动画的重点页检查初始、中间和最终状态。优先实际放映并观察；需要方便复核时，可用 PowerPoint 原生动画视频导出。
3. 若为视频在独立副本上将点击触发改为自动推进，只改变触发时机，保留阶段顺序、组内对象和效果。正式稿继续按用户要求点击触发。视频检查不能声称验证了真实鼠标点击。
4. 给完整最终画面留出阅读停顿，抽取阶段画面检查模块与连线同步；完整静态图正确不代表动画正确。
5. 若工具无法捕获放映状态，记录实际采用的替代验证及其边界，不以动画 XML 数量代替视觉检查。
6. 最终保存后重新渲染，核对交付文件和检查稿。需要逐像素比较时使用同一 PowerPoint 渲染尺寸与环境；这只验证视觉一致性，不验证科学结论。

PowerPoint 原生视频导出接口：[Presentation.CreateVideo](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.presentation.createvideo)。具体参数和工具支持以当前环境为准。
