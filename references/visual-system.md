# 科研视觉系统

## Nature figure 风格的可执行定义

图像生成提示词和矢量成稿都落实以下特征：白或浅底、精准科学图元、清楚的分面板与阅读顺序、精细而克制的线条、统一图例、语义配色、数据和机制关系清晰。曲线、树、网络、矩阵、文档、状态和箭头按研究内容绘制，信息完整且投影可读。

同一章保持字体、线宽、图元细度和色彩语义一致；不同页根据主题选择过程、对照、汇合、证据或反馈结构。参考 [已认可的文献机制页](../assets/approved-research-examples/literature-mechanisms.png) 的信息密度与对象完成度，不将所有页套成同一种卡片图。

## 字体与布局

先确认本机字体。中文衬线大标题建立学术层级，无衬线正文和图注保持投影清楚。按用户参考选择具体字体。样页测试中文、英文、空格、公式和上下标，检查 PowerPoint 实际渲染；必要时对空格或符号设置独立字体 run。

主标题、章标题、面板标题、标签与图注形成稳定字级。通过精炼、分层和拆页安排文字容量，主要结论不塞入脚注。各对象区域和文字锚点预留边距，检查遮挡、重叠、截断和连线穿字。

## 色彩与主线导航

章节页采用白底与宽蓝横幅，目录和导航突出当前章。正文配色跟随选定总览方案，主色、强调色、辅助色各有语义；反馈线、候选和证据在全稿保持相同编码。

四套总览采用明显不同的色彩组合及对象细节。颜色之外同步用文字、位置和线型表达含义。分类数据使用分类色，连续量使用连续色阶。大面积背景克制，科学关系优先。

## 图表与机制

- 堆叠文档用于档案、局部曲线用于序列、矩阵用于关系、树或网络用于相应模型，箭头连接实际输入输出。
- 当前流程、历史依赖和反馈使用区分清楚的线型与图例。
- 候选池与单个候选分别设置锚点，箭头端点落在对应可见边界。
- 数据图保留真实趋势、尺度和离散性；示意图注明示意，相关小图使用一致构造。
- 密集数据点按矢量组管理；网格、图例、分布和科学含义完整保留。
