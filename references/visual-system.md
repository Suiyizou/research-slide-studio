# 科研视觉系统

## Nature figure 风格的可执行定义

图像生成提示词和矢量成稿都落实以下特征：白或浅底、精准科学图元、清楚的分面板与阅读顺序、精细而克制的线条、统一图例、语义配色、数据和机制关系清晰。曲线、树、网络、矩阵、文档、状态和箭头按研究内容绘制，信息完整且投影可读。

生图前按 [生图质量与风格对齐](image-reference-quality.md) 绑定实际正例，将这些原则展开为可见图元和构图；返回后分别检查整页、全尺寸和关键局部。风格名和模型名不作为质量凭据。

逐页把这些特征展开为 [逐页提示词契约](page-image-prompt-contract.md) 的八段文本。借鉴 nature-figure 的证据架构：一页围绕一个科学问题，面板各有论证职责；机制与综合页可采用主视觉加辅助证据，公平比较可等权布局。不将 Nature 风格等同于固定三栏、卡片网格或某一种配色，也不照搬论文小字号。

同一章保持字体、线宽、图元细度和色彩语义一致；不同页根据主题选择过程、对照、汇合、证据或反馈结构。参考 [已认可的文献机制页](../assets/approved-research-examples/literature-mechanisms.png) 的信息密度与对象完成度，不将所有页套成同一种卡片图。

## 参考优先级与完成度

当前用户指定原图 → 本任务已选定总览与独立参考 → 历史生图原稿 → 通用风格原则。科研内容先核对，但只修正具体错误对象；配色、容器、层级与其他正确细节继续保留。Nature figure 不等于全页白底细线、巨幅留白、无填色或小字号。

用正文区域检查“输入怎样变化、方法内部做什么、输出是什么、为何引出本页结论”。已知的结构、状态、图例、局部放大和机制说明要完整；信息不足先补材料，信息过多拆页。保持投影可读的中高密度，标题与边距给主体图留出空间。

提示词按已选参考描述线宽层级、浅色分区、曲线、内部结构、对比色与图例。用户没有选择极简风格时，不追加 `sparse`、`vast negative space`、`tiny labels`、`few details` 或“为了便于 SVG 重建而简化”。不笼统禁止所有边框、卡片、渐变：有语义的分组容器与轻填色正是已认可参考的一部分。

对照时逐项检查参考中的容器层次、局部结构、图例、曲线与字体层级。去掉科学错误需记录具体修改；不能以“证据边界”或“纯矢量”为由一并删掉不涉及事实的视觉结构。几何可以保真且可编辑。

## 字体与布局

先确认本机字体。中文衬线大标题建立学术层级，无衬线正文和图注保持投影清楚。按用户参考选择具体字体。样页测试中文、英文、空格、公式和上下标，检查 PowerPoint 实际渲染；必要时对空格或符号设置独立字体 run。

主标题、章标题、面板标题、标签与图注形成稳定字级。通过精炼、分层和拆页安排文字容量，主要结论不塞入脚注。各对象区域和文字锚点预留边距，检查遮挡、重叠、截断和连线穿字。

## 色彩与主线导航

章节页采用白底与宽蓝横幅，目录和导航突出当前章。正文配色跟随选定总览方案，主色、强调色、辅助色各有语义；反馈线、候选和证据在全稿保持相同编码。

四套总览采用明显不同的色彩组合及对象细节。颜色之外同步用文字、位置和线型表达含义。分类数据使用分类色，连续量使用连续色阶。大面积背景克制，科学关系优先。

## 图表与机制

- 堆叠文档用于档案、局部曲线用于序列、矩阵用于关系、树或网络用于相应模型，箭头连接实际输入输出。
- 当前流程、历史依赖和反馈使用区分清楚的线型与图例。
- 候选池与单个候选分别设置锚点，箭头端点落在对应可见边界。
- 数据图保留真实趋势、尺度和离散性；示意图注明示意，相关小图使用一致构造。
- 密集数据点按矢量组管理；网格、图例、分布和科学含义完整保留。

## 最终画面与版式验收

验收覆盖最终 PPT 的全部页面，包括未生图页、目录、章节页和附录。先查看全稿缩略图，再看逐页实际展示尺寸，最后放大文字与图像交界、图标、曲线和连接端点；不能只检查生图原稿或抽查几个精美页。

**边界与清晰度**：逐页检查文字是否与图像粘连、底色不匹配、残字重影、模糊块、灰白补丁、锯齿碎边、断线或不明色块。区分真实图中的合理透明度/景深和重建产生的污损。发现问题时定位到具体对象，重绘图形、重新排字或恢复正确图源，不用新的矩形遮盖。工作副本移开可疑文字，确认底层干净；重新渲染同一区域复检。

**三线表及类似布局**：检查实际画面，不只统计 PPT 表格对象。大段文字按左右列排列、横线或浅色条带分隔多行、每行“名称—说明—不足”，即使由矩形和文本框拼成，也属于应排查的伪表格。列出所有命中页码；叙述性的意义、进展、不足、问题页整改为流程箭头、并列机制、瓶颈放大或关系图，用图形解释变化和联系。不能只删横线、改圆角或换背景色后保留原来的文字表格结构。真实数值对照表确有用途时记录保留理由；不为避免表格把数据改造成暗示因果的流程。

**整改与留证**：在 `checks/final-review.md` 逐页记录“页码｜渲染图｜边界清晰度｜版式类型与表格式布局判断｜问题位置｜整改方式｜复检图与结论”。无问题页给出实际观察；有问题页在整改后补同位置的新截图。未修复问题不标通过，脚本对象检查通过不能代替画面验收。全稿目录与衔接另按 [主线终检](research-navigation.md#整稿目录与章节终检) 记录。
