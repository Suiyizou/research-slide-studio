# 字体、配色与科学图

## 字体

先检查本机实际安装的字体。中文宋体类标题可建立学术气质，无衬线正文适合投影阅读；字体选择取决于用户参考，不固定要求宋体。例：Source Han Serif SC Heavy 标题、Noto Sans SC 正文、Arial 数字或空格回退。

必须测试包含中文、英文、空格、数学符号与上下标的样页。字体名称存在不代表每个字符能在 PowerPoint 正确渲染。实际案例中某宋体字体的空格显示方框，改为空格独立使用无衬线字体的富文本 run 后再验证。

以投影可读为准，优先缩短或分层文本，避免把字体不断缩小。脚注可以小，但不能用脚注承载主要结论。

## 配色

选一个深色主色、一个重点色及少量浅色背景，固定颜色的语义。示例：墨紫 #38385B 表示主体；灰粉 #9C5875 表示反馈；浅紫 #EEF0F7 表示背景；正文 #30323E。这是一个可选方案，不是 Nature 官方配色。

颜色之外同时提供文字、位置或线型编码。浅底深字；避免饱和色铺满大面积。数据图遵循统计含义：分类色不暗示数值次序，连续量使用连续色阶。

## 机制图与叙事

- 矩形只是其中一种表达：可用堆叠文档表示档案、矩阵表示张量、局部序列表示时间输入、扇出箭头表示候选关系。装饰对象不得改变算法含义。
- 实线用于当前信息流、虚线用于离线学习或辅助依赖时，提供足够的文字说明。
- 箭头连到整个候选池与连到某一个候选含义不同；透明锚点要与可见边界一致。
- 抽象预算条容易被读成真实比例：没有数据时用文字或明确的“示意”标注。
- 不平滑离散残差或阶跃数据来增加美观。图表默认值可能与源码意图不同，要检查目标应用实际渲染。
