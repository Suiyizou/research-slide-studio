# 图形与文字分离的省预算流程

## 四套总览与章节分配

本用户的新一轮科研汇报生图探索，默认先生成四套总览缩略方案，再展开关键内容页。四套针对同一条研究主线展示可比较的代表页，而非四个几乎相同的蓝色框架。已确定方向的局部修订直接复用，不机械重走抽卡。

- **配色有差别。** 四套分别探索明显不同的主色、辅色和强调方式，并保持语义配色可辨；只换色号或深浅不算充分区分。不要预设所有任务都必须蓝 / 紫红。
- **构图有差别。** 同一内容分别探索关系三角、纵向或横向过程、局部机制对照、多视角汇合、开放式科学图等合适结构；不只改变卡片数量或标题位置。
- **对象表现有差别。** 探索档案、模型机制、特征编码、局部曲线、预算状态和反馈箭头的不同组织方式，保留课题真正需要的信息，不靠装饰填满留白。

逐套比较主线是否清楚、必需信息是否齐全、对象比例与留白是否合理、关键细节能否被矢量重建。记录选用理由和参考—页面对应关系。可以选一套贯穿，也可以把不同方案用于不同章节；组合时统一全稿字体、边距、语义颜色和导航，同章保持相近的图元细度与完成度。不同章节无需重复同一种布局。

先完成选案再生成重要内容页，深化图数量服从本次用户要求。封面已有用户背景时直接复用，把生图投入总流程、研究问题、机制对照和总结等关键页。使用当前环境可用的图像生成能力，只有实际可确认时才记录具体模型版本。

## 制作顺序

对于这个科研汇报系列，先确认图形，再调整文字。生图可以参考 Nature figure 的科学图表达：语义配色、清楚的阅读路径、精细图标、曲线、图例与对象层级，不虚构结果。不要把该参考解释为一律删减细节或套通用方框；它不表示 Nature 官方模板或发表许可。

1. **检查可复用图源。** 已有图直接复用组件、坐标、图元 ID 和配色，仅修改必要参数，不重新逐项描绘。
2. **选择图源路径。** 结构明确的机制、流程和对照图优先直接设计 SVG；需要探索构图时先按上节完成四套总览选择，再生成少数重要内容页并按对象精修。明确提示主模块、必需小图、图例、线条虚实、箭头方向和文字区域，避免只写笼统的风格词。参考图可用中文或英文；文本需重新核对，后续在独立文字层编辑。
3. **先做纯图形 SVG。** 重建图标、模块、曲线、矩阵、箭头、渐变与层级，保留文字的留白与锚点。禁止图片切片、嵌入位图或无含义路径堆叠冒充对象级矢量。
4. **检查图形后处理文字。** 标题、说明、标签、公式、图例文字留在独立坐标文件或 PPT 原生文字层，后续统一调整内容、语言和字体；将其锚定到对应对象的预留区域，逐一检查居中、基线、边距及连线避让。内容超出容量时拆页，不用覆盖、截断或挤压解决。图标内部必需的问号等符号可用路径重建，不把正文转成轮廓。
5. **进入 PPT。** SVG图形可转换或映射为原生形状，文字保持文本。MCP负责排版、分组、动画和实际渲染精修；仍须区分可缩放SVG和真正可逐项编辑的PPT对象。

## 控制投入

- 精细复刻集中在关键方法图。普通内容页使用已确认版式与组件，不要求每页重新生图和描绘。
- 使用一个几何图源生产 SVG 和 PPT 图形；独立文字层保留坐标关系，避免分别手工维护两套几何。
- 先验收一张关键图的构图、图元和导入效果，再复用到后续页。修复时局部修改并重渲染受影响的部分；没有新问题，不继续扩大检查范围。
- 在独立制作上下文中只带当前页内容、参考图、已确认参数和图源。当前会话已读的指南不反复通读；按当前环境和技能要求加载必要文档。此建议不授权自动新建任务。
- 预算评估使用可获得的实际用量，区分输入、缓存输入、输出及其中的推理；没有账单数据不推算实际金额，不把尚未实测的节省比例写成事实。
