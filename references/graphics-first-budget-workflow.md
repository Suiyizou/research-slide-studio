# 生图覆盖与制作流程

写提示词前查看 [历史生图原稿库](generated-reference-library.md)，打开主题对应的完整原图和提示词，提取对象细度、阅读路径及信息容量。可编辑 PPT 样张辅助重建。历史库用于设计参考；新稿仍按下面的四套总览和约 50% 独立内容页数量实际生图。

## 数量、顺序与计算口径

新稿执行“主线与页序 → 四套生图总览 → 选案 → 约 50% 页面独立生图 → 一比一矢量重建 → PPT 排版与验收”。调用图像生成工具产出参考图，文字描述、搜索到的图片、代码绘制的草图均不替代这一步。

N 为最终 PPT 的总页数，包括封面、目录、章节过渡、正文和附录；逐页内容参考目标 M = ceil(N × 0.5)。例如 16 页安排 8 页，22 页安排 11 页，25 页安排 13 页。优先覆盖图形承载信息的正文；已有封面图直接使用，不占逐页生图覆盖数。

四套总览用于选案，不计入 M。每个纳入覆盖的页面绑定一张主题独立的最终参考；同图多用、裁切、改分辨率、重抽和废弃图不增加覆盖页数。参考中包含多个小面板仍只覆盖其对应的一页，不按小面板数量计数。

局部修订延续已经确认的参考和视觉体系，更新改动页的参考与重建；重新设计整稿时按最终 N 核算覆盖。只解释图、讲论文或写讲稿时，直接完成该任务。

## 四套总览如何拉开差异

四套分别实际生成一张总览，每张展示相同主线下的若干代表页，方便比较。

- **配色**：主色、辅色和强调方式明显不同；例如藏蓝与青绿、石墨与橙、靛蓝与莓红、灰绿与金。图元颜色保持明确语义。
- **构图**：探索横向过程、纵向递进、机制对照、分面板证据、汇合关系或开放式科学图；不仅换标题位置或卡片数量。
- **细节**：按课题绘制档案、模型机制、特征、数据图、状态、图例与连接路径。对象细度与信息容量用于选案。

比较主线、完整性、阅读路径、留白和重建可实施性，选出方案或按章节组合。自行完成常规选案；用户明确要亲自选择时展示四套并等待选择。

## 逐页参考的生成约束

先写本页内容卡：章节、核心问题、输入输出、必需对象、主结论或待检验问题，以及与前后页的区别。再按内容卡写生图提示词。

提示词包含：

1. **Nature figure 科研表达**：白或浅底，清楚的多面板层级，精准线条，克制的渐变，语义配色，精细科学对象，出版级图例与箭头，适合 16:9 投影阅读。
2. **本页专属内容**：列出具体输入、方法对象、状态、输出与必要小图；标题和文字区域按最终语言预留。
3. **阅读路径与几何**：主模块比例、连接方向、线条虚实、图例位置和留白。每条箭头表达明确关系。
4. **与其他页区分**：声明这页采用的关系形式，避免套用相邻页构图。同章统一线宽和完成度。

参考可为中文或英文。生成后先检查语义与布局，修正缺失对象、错误公式或方向后再选定。提示词、返回图和最终选择保存到本次工程目录。数量以最终被不同页面采用的参考为准。

## 图形优先的落地顺序

1. 为选定参考建立对象清单与边界框，锁定同画幅几何。
2. 重建纯图形 SVG，建立语义组和稳定 ID，文字留出锚点。
3. 将密集重复细节合并为矢量组或复合路径，保留参考的视觉与科学关系。
4. 加入独立文字层，核对字级、语言、对齐、基线与箭头避让。文字装不下时拆页并更新参考分配。
5. 将图形和文字组织进 PPT；按同样几何维护 SVG 与 PPT，复用组件而不复制整页主题。
6. 保存参考 / SVG / PPT 对照与叠加检查文件，修复本页差异后推进后续页。

其余页面用已确认的矢量组件与导航体系设计，并根据本页内容重新组织。经选定生图页必须沿参考重建，不能改走通用框架。

## design-plan.json

完整新稿使用以下字段；路径相对该清单所在目录。`slides` 覆盖全部页码。四套总览各有独立图像文件，纳入覆盖的内容页各有独立参考、提示词、SVG、文字层和验收文件。

```json
{
  "total_slides": 22,
  "new_visual_direction": true,
  "overviews": ["overview/a.png", "overview/b.png", "overview/c.png", "overview/d.png"],
  "slides": [
    {
      "slide": 1,
      "role": "cover",
      "message": "本次研究主题",
      "visual_form": "user_cover",
      "generated_reference": false
    },
    {
      "slide": 8,
      "role": "content",
      "message": "不同文献分别已经完成哪些判断与输出",
      "visual_form": "multi_paper_mechanisms",
      "generated_reference": true,
      "reference": "references/08.png",
      "prompt": "prompts/08.txt",
      "svg": "svg/08.svg",
      "labels": "labels/08.json",
      "comparison": "checks/08-side-by-side.png",
      "overlay": "checks/08-overlay.png",
      "reviewed": true
    }
  ]
}
```

以上展示字段用法，实际清单列齐 1—22 页，安排 11 个不同页面的 `generated_reference: true`。局部修订保留整稿已有记录，已选定方向使用 `new_visual_direction: false`。

执行 `python scripts/audit_design.py <design-plan.json>`。脚本核对覆盖、文件、重复参考和 SVG 内的位图；并排与叠加图由 agent 实际查看后填写 `reviewed`。脚本结构检查与人工画面检查共同完成验收。

## 组件复用

`../assets/agent-workflow/graphics.svg` 与 `labels.json` 提供对象分组和独立文字示例；`editable-template.pptx` 提供原生对象与讲解阶段。复用时保持本页参考的几何，不以省工为由改变构图。修改节点后同步调整连接路径，或整体移动语义组。
