# 图形与文字分离的省预算流程

## 制作顺序

对于这个科研汇报系列，先确认图形，再调整文字。生图可以采用 Nature 风格的简洁科学图视觉：限定语义配色、清楚的阅读路径、精细图标与曲线、不虚构结果；这不表示 Nature 官方模板或发表许可。

1. **检查可复用图源。** 已有图直接复用组件、坐标、图元 ID 和配色，仅修改必要参数，不重新逐项描绘。
2. **选择图源路径。** 结构明确的机制、流程和对照图优先直接设计 SVG；需要探索构图的少数关键页先生图，再按对象精修。生图提示保留清楚的文字留白，图中文字只作为位置提示。
3. **先做纯图形 SVG。** 重建图标、模块、曲线、矩阵、箭头、渐变与层级，保留文字的留白与锚点。禁止图片切片、嵌入位图或无含义路径堆叠冒充对象级矢量。
4. **检查图形后处理文字。** 标题、说明、标签、公式、图例文字留在独立坐标文件或 PPT 原生文字层，后续统一调整内容、语言和字体。图标内部必需的问号等符号可用路径重建，不把正文转成轮廓。
5. **进入 PPT。** SVG图形可转换或映射为原生形状，文字保持文本。MCP负责排版、分组、动画和实际渲染精修；仍须区分可缩放SVG和真正可逐项编辑的PPT对象。

## 控制投入

- 精细复刻集中在关键方法图。普通内容页使用已确认版式与组件，不要求每页重新生图和描绘。
- 使用一个几何图源生产 SVG 和 PPT 图形；独立文字层保留坐标关系，避免分别手工维护两套几何。
- 先验收一张关键图的构图、图元和导入效果，再复用到后续页。修复时局部修改并重渲染受影响的部分；没有新问题，不继续扩大检查范围。
- 在独立制作上下文中只带当前页内容、参考图、已确认参数和图源。当前会话已读的指南不反复通读；按当前环境和技能要求加载必要文档。此建议不授权自动新建任务。
- 预算评估使用可获得的实际用量，区分输入、缓存输入、输出及其中的推理；没有账单数据不推算实际金额，不把尚未实测的节省比例写成事实。

## 可复用单页样张

- `../assets/agent-workflow/graphics.svg`：107条路径、115个矩形、50个圆、3个椭圆；10个语义组；无 image、无 text 图元。图内曲线、置信带、残差矩阵与预算是教学示意。
- `../assets/agent-workflow/labels.json`：独立文字内容、坐标、基线、区域宽度与建议字体。先改措辞与语言，再确认文字不会影响图形结构；这些字号是样张参数，不是所有任务的固定标准。
- `../assets/agent-workflow/editable-template.pptx`：单页原生图形与独立文字，7个点击讲解阶段，可替换内容和调整动画。

保留既有22页模板；这个样张是图元复用示例，不替代所有页面的模板。SVG和PPT的自定义曲线不承诺随节点自动吸附；改节点位置后调整对应路径，或整体移动语义组。
