# 生图质量与 Nature figure 风格对齐

本规范用于科研 PPT 的生成参考。与八段提示词配合执行：内容卡确定“画什么”，本规范确定“画到什么完成度”。调用成功、写了 Nature figure、图中有很多细节，都不等于画面合格。

## 1．先确定可以对照的视觉目标

按主文件路由读取 nature-figure 的科学表达原则，并查看当前用户认可的全尺寸原图。选定总览后，逐页沿用其字体层级、语义色与图元细度。Nature figure 在此指科研关系、证据层级和精细图形表达；本任务仍按 16:9 投影与 PPT 编辑性制作，不自动改成期刊小字号或极简线稿。

从 [历史生图原稿库](generated-reference-library.md) 选与本页相符的 1—3 张图，实际打开完整图像和对应提示词。优先使用当前用户给定的正例：文献机制参考 R06/R07，总流程参考 R04，诊断与消融参考 R03。参考继承视觉表达，具体内容从本次材料重写，不复制旧课题的模型与结论。

在已有内容卡“视觉与参考”中写清：

- 哪张图负责风格、哪张负责构图、哪些图提供科学内容；单张可承担多个角色，但逐项说明。
- 继承哪些具体特征：例如主次面板比例、轻填色分区、细线与深色重点的对比、机制内部结构、标签层级、反馈路径。
- 本页替换哪些内容；与邻页共用哪些颜色和符号；本页在哪个关系或重点上变化。

调用生图工具时实际附上选定图像；仅在提示词中提到文件名或 Nature figure 不会传递图像。使用工具支持的参考图参数，按该工具说明操作。截图用于风格参照时明确忽略软件边框、选中框、工具栏和红色批注；能找到干净原稿时优先使用原稿。

## 2．把“精美”展开为可见特征

| 维度 | 提示词中说明的正向要求 | 返回图的检查要点 |
|---|---|---|
| 构图与重点 | 指定主机制、阅读起点、终点与辅助信息的位置；对照页说明等权关系 | 缩略图也能看出主线；总流程与总结各有职责，不连续照搬整页布局 |
| 信息与细节 | 逐对象描述有来源的内部结构、输入、变换与输出；用局部放大解释关键步骤 | 方法内部能辨认，图例与辅助图有作用；细节来自科学结构，不能用随机点阵或纹理填满空白 |
| 形状与轮廓 | 完整圆/矩形/图标、平顺曲线、连续箭头、明确端点、可区分的线宽层级 | 无糊边、断边、残影、碎块；网络节点能区分，线不穿字 |
| 层次与分组 | 用轻填色、适量容器、对齐、间距和局部渐变组织语义层次 | 主体有对比，背景从属；不能变成只有淡细线的稀疏草图，也不靠粗框和炫光制造重点 |
| 配色与连续性 | 明确对象到颜色的映射，保留少量强调色；跨页相同对象保持身份 | 配色克制但有足够对比；同章完成度一致，不突然换成卡通、商业看板或重立体装饰 |
| 文字与比例 | 标题、面板名、短标签和说明分级，给文字留足锚点和间距 | 以整页展示尺寸检查可读性；拥挤通过改布局或拆页解决，不能统一缩成小字 |

中高信息密度用于科研正文；目录与章节页承担导航，保持醒目与简洁。丰富不等于每页堆满图标，留白用于分组和阅读，不代替已明确的科学内容。用户认可的浅渐变、卡片容器或强调色可以保留，不笼统禁止这些元素。

明确要求完成图具有精修科学插图的边缘质量与排版完成度，而非草稿、模糊概念图或贴图拼盘。图中结构应足够清楚，供后续按对象重绘；不能为降低重绘工作量预先删掉关键细节。

## 3．嵌入八段提示词的写法

下面的视觉段落用于改写第 07 段，不替代第 01—06 段的具体科学内容。按本页实际附图、对象、构图和色表填写，不机械复制未提供的参照。

> 采用所附认可原图的精修科研插图完成度：继承其清楚的主次关系、轻填色分区、准确轮廓、机制内部细节与独立标签尺度。本页的对象、输入输出和连接严格按前述内容绘制。主机制在指定区域形成明确阅读路径，辅助图解释对应环节。边界完整，曲线平顺，箭头端点清楚，标签贴近对象且相互留出间距。以语义色和局部对比突出关键变化；保留投影可读的中高信息密度和必要图例。背景安静，细节清楚，同章图元与字体层级一致。构图服从本页任务，达到可以逐对象重绘的完整设计稿质量。

第 08 段只追加与本页有关的偏差约束，例如“不要把知识图谱画成无标注的彩色点云”“不要用同一个网络图标代替三个不同模型”。不能只堆砌 beautiful / professional / 4K / Nature；也不向每张图复制大量无关禁词。

科学证据约束用简洁准确的对象和关系表达。对未证实结果标注方案或示意，同时把已知结构画完整；不要用大段免责声明或空白框占据主体设计区。

## 4．返回图要实际选优和修正

把检查写入现有 `checks/NN-prompt-review.md` 的返回后部分，不另建重复流程。记录图像真实尺寸，并按三种视图检查：

1. **整页缩略**：主线是否突出，布局是否符合本页职责，与选定总览是否连续。
2. **全尺寸**：对象清单与科学关系完整，字级、图例、间距和分区清楚，密度适合投影。
3. **关键局部放大**：细图标、曲线、网络、文字邻接区是否完整；无碎块、假细节、文字融合、糊边或不明连接。

分别记录科学内容、构图与风格、图元完成度、文字可读性；每项用具体观察和问题位置说明，不预填“全部通过”。结构错、关键对象缺失、主次不清、密度明显偏离正例、图形普遍模糊时，不选为最终参考，也不计入有效覆盖页。

纯错字且图形完整时，记录正确文本与锚点，重建时修正。局部图形缺陷做定向编辑；整页构图或风格跑偏则修改对应提示词段落并重生成。修正时写明“保留哪些部分、修改哪个对象、达到什么可见结果”，沿用已通过的内容卡与风格参照；不因重抽而重置章节视觉系统。

新稿仍先生成四套明显不同的总览再选案；无需为每一页额外强制四次生图。原图已经达标时进入重绘，不反复生图；原图好、复刻差时修复重绘过程，不用更换生图来掩盖。

## 5．参考图与成稿分别验收

通过的参考图锁定构图与信息细度，后续执行 [按语义对象重绘](faithful-vector-reconstruction.md)。最终 PNG/PDF/PPT 渲染与参考进行同尺寸并排及叠加检查。参考图好看不能抵消成稿残字、补丁、碎边或错位；PPT 对象可编辑也不能抵消画面失真。

模型或接口名称只记录实际可见信息；“换了更强模型”“已调用 nature-figure”均不能替代上述画面验收。
