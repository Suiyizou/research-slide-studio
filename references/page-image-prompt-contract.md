# 逐页生图提示词契约

本规范固定每页的信息字段、科学关系和检查方法，供不同主模型执行同一标准；不固定每页的面板数量、排列、配色或构图。适用于独立内容参考；四套总览沿用同一份科学内容卡，分别探索视觉方案，不把八段全文缩印进总览小格。

## 1．先写内容卡，再写提示词

为每张拟生图内容页保存 `prompts/NN-brief.md`。以下字段逐项填写；不适用的字段写“不适用：原因”，不能静默跳过。只保留与本页科学论证有关的内容，不为凑字段增加对象。

| 必填字段 | 写到什么程度 |
|---|---|
| 页面任务 | 页码、章节、受众、本页核心问题、一句应带走的信息；研究方案用待检验问题，不写成已有结论 |
| 来源与证据 | 使用局部编号 S1、S2 等，记录可定位的材料段落、图号、数据文件或用户明确给定的前提；逐条关联关键机制与结论。区分文献结论、已完成结果、研究方案、教学示意和未知 |
| 对象清单 | 每项用稳定 ID；列名称、科学角色、可见内部结构、输入、输出、证据类别和来源编号。信息对象可用序列、矩阵、树、网络、状态、装置等具体图元，按来源选择 |
| 关系清单 | 每条用 `起点 ID → 终点 ID｜关系｜传递对象或量｜证据类别｜来源`；标明数据流、变换、选择、时间顺序、反馈、相关或因果。比较、分组可用括号或对齐，不必画箭头 |
| 面板职责 | 每个面板回答的子问题、主要对象和支持作用；确定主视觉及其突出理由。单一机制图可只有一个面板 |
| 图表处理 | 逐个标为真实数据图、已有来源图、定性示意或预留区域；列变量、单位、样本/重复与不确定性定义（来源有才写）。真实图记录对应数据/图源；示意列明允许表达和不能暗示的关系 |
| 标签与符号 | 确定标题、面板标题、短标签、图例、变量和公式的准确写法；保留模型名大小写。说明文字预留位置及独立文字层需求 |
| 构图与连续性 | 选关系形式与阅读路径；写主次比例、模块位置、连接端点、留白、文字区域，以及与前后页的分工。需重复的对照布局写理由 |
| 视觉与参考 | 章节语义色映射、线型、需要继承的图元细度；实际附图清单及各图用途（风格/构图/科学内容），没有附图写无 |
| 禁止暗示与未知 | 本页最易混淆的输入输出、阶段、时间/因果关系、证据强度及未核实项；写具体对象和错误关系，不只写“不要幻觉” |

主张依赖的来源不足时，先检索或查阅已有材料；仍无法确认则把相关内容降为明确的研究假设，或暂不绘制该机制。关键输入输出或机制方向尚不明确时，先解决该页的内容缺口；其他已明确页面可继续。不能把未知字段交给生图模型补全。

## 2．固定科学细度，按内容决定对象数量

用下面的规则判断“细节充分”，不以字数、图标数或提示词长度替代：

- **方法模块可辨认**：画出来源支持的内部步骤、结构或变换，能看出它如何把输入变成输出。只写模型名、放通用大脑图标或装饰齿轮，不算解释机制；来源未说明内部机制时，保留黑箱并注明边界，不能杜撰结构。
- **对象有可视内容**：序列体现轴或顺序，矩阵说明行列含义，候选池与被选候选区分，状态/阶段有标记。图元选择服从对象，不强制每页出现树、矩阵或网络。
- **每条连接能读出意义**：明确传递什么、从哪里到哪里、发生在哪个阶段。训练/验证/测试、离线/在线、历史/当前、已观测/待预测按课题需要区分，避免数据泄漏与时间倒置。
- **每块辅助图有职责**：回答机制、对照、诊断、鲁棒性、边界等一个具体问题；与主图保持变量、颜色和模型身份一致。没有论证作用的小图删除。
- **每个结论有证据边界**：方法能力递进不自动表示发表时间递进；预测误差不等于实测误差；相关不画成因果；拟议反馈不画成已有验证；“有改善”不自动表示统计显著。

## 3．Nature figure 风格的固定底层

同时执行 [生图质量与风格对齐](image-reference-quality.md)：实际查看并传入选定原图，明确继承与替换项，再将可见质量要求写入第 07 段。既有八段科学内容不能代替构图和视觉完成度的具体描述。

从 nature-figure 采用“一页一个科学问题、面板承担不同证据职责、视觉层级服从证据层级”的设计原则。采用 16:9 投影阅读尺度：字号清楚，信息保持用户认可参考的中高密度与精细程度；过多内容拆页。优先继承实际附图的构图、层次、轻填色和对象细节，不自动切换为稀疏论文线稿。

每条完整提示词都落实以下约束，可按章节换配色，但保留语义一致性：

- 白色或极浅背景；用留白和对齐组织层级。显微/实验照片仅使用真实来源图，在必要的图像区域保留原背景。
- 对机制与综合页，优先一个主视觉搭配必要辅助图；公平对照、同条件比较可用等权面板，不强制所有页都有大主图。
- 图元精准、轮廓清楚，轻量填色与克制渐变，避免装饰阴影、无意义 3D 和玻璃质感。精细度来自科学结构，不来自纹理堆砌。
- 一组中性色、一组主要语义色及少量强调色作为起点；方法身份和状态跨面板一致。分类用分类色，连续量用连续色阶；有中心值才用发散色阶。颜色同时配合标签、形状或线型。
- 主机制与关键证据最醒目；基线、网格、容器边界从属。优先对象旁直接标注；需要图例时集中放置，说明线型及状态。
- 多面板按需使用左上角小号粗体 `a`、`b`、`c`，不强制每页有面板字母。可比图对齐绘图区与尺度；共享坐标范围仅在变量和单位可比时使用。
- 文字在投影尺度清楚可读，标签短而准确；标题、图注及复杂公式预留独立文字层。标签拥挤时精炼、改布局或拆页，不能靠缩成脚注解决。

风格参考只继承视觉语言，不继承其中的实验趋势、模型结构、数字或文献结论。提示词不能要求“自动补全合理科学细节”。

## 4．构图自由度：先选关系，再定位置

以下是候选，不是每页轮流套用的模板。选择一种主关系，可组合辅助关系；在内容卡写一句选择理由。每页只需选定一个合理方案，不强制额外生成多份逐页备选。

| 本页任务 | 可选构图 | 应保持的科学边界 |
|---|---|---|
| 机制/方法 | 主机制加局部放大、横向过程、纵向层次、分支合流 | 箭头表示实际变换；放大区域与主图对象对应 |
| 文献进展/定位 | 并列机制、能力地图、中心问题配周边证据、分组对照 | 各方法输入输出分别完整；跨文献连接须有依据，不能凭位置暗示承接或年代 |
| 研究意义/问题 | 多源汇合、瓶颈放大、现象与需求对照、尺度递进 | 背景事实、研究需求与拟议方案分层 |
| 实验/消融 | 受控成对比较、主结果加诊断、条件矩阵加真实图区 | 控制变量、样本单位、指标方向和不确定性可核对 |
| 总框架/闭环 | 离线与在线双通道、跨阶段泳道、反馈回路、分层系统 | 区分执行、验证、更新及可用信息时点 |
| 总结/下一步 | 证据汇合、贡献与适用边界、已完成与待验证分区 | 不把待验证计划画成已获得的结果 |

提示词给出主要区域的相对位置和大致比例即可；只有避免歧义时才加归一化边界框。不要对每个点写死坐标。先保证关系正确与可读，再在选定参考上测量并锁定重建几何。

相邻页先比较论证职责。职责不同则改变主关系或视觉重点；同一受控比较、同类案例或递进讲解需要复用布局时保留一致性，不为了“每页不同”破坏可比性。

## 5．实际提交的提示词：固定八段

每页保存 `prompts/NN.txt`，按以下八段顺序写成可独立理解的完整提示词。标题可保留英文，正文中文或英文均可；使用哪种语言不改变科学内容要求。将内容卡展开为具体描述，不将内部来源路径或长篇文献摘要直接塞入图中。

```text
01 OUTPUT & MESSAGE / 输出与核心问题
生成 16:9 科研汇报内容页的设计参考，采用 Nature figure 视觉语言。
这是待核对和矢量重建的参考图。受众：[具体受众]。
本页回答：[单一科学问题]；应传达：[来源支持的一句话或待检验问题]。
标题：[准确标题]；章节位置：[章节]。

02 EVIDENCE BOUNDARY / 来源与证据边界
[列明关键机制/结论及证据类别，写出所需来源事实的实质内容]。
[哪些是已验证，哪些是方案/示意，哪些未知；不能暗示什么]。

03 ENTITIES & INTERNAL DETAIL / 对象与内部结构
[逐个描述主对象：短标签、科学角色、可见内部结构、输入输出]。
[需要的局部小图、状态、候选、时间/阶段边界及其职责]。
细节仅来自给定内容；未知内部机制保持黑箱并标明。

04 RELATIONS / 科学连接
[逐条写起点、终点、传递对象/量与关系类型；指定方向和端点]。
[分组、对照、相关关系如何表达；虚实线和反馈的含义]。
不将空间邻近、能力递进或相关性暗示为时间顺序或因果。

05 COMPOSITION / 构图与阅读路径
[本页选择的主关系形式、主视觉、面板职责和阅读顺序]。
[主要区域位置与大致比例、标题/标签/图例/数据图预留区、留白]。
[与相邻页的分工或有理由复用的对照结构]。

06 QUANTITATIVE PANELS & LABELS / 图表与准确标签
[逐图指定真实图源、定性示意或预留区；给定变量、单位与证据边界]。
[真实定量图的区域只留占位，不合成结果；定性示意明确标注“示意”]。
[列准确短标签、面板名、图例、符号，以及复杂公式的留白区域]。
标签靠近对应对象；最终文字将独立校对和排版。

07 VISUAL SYSTEM / 视觉系统
[白/浅底，图元细度、主次层级、语义色映射、线型、标签及图例方式]。
[对齐和尺度可比要求；在 16:9 投影下保持清楚可读]。
[实际附图分别用于风格/构图/科学内容，描述继承和替换的内容；无则写无]。
完成精修科学插图：轮廓完整、曲线平顺、连接端点明确，主次分区清楚。
以有来源的内部结构形成丰富细节，保留所选参考的轻填色层次、对比和信息容量。
按本页职责安排构图，不能用空框、随机纹理、模糊点云或超小字代替内容。

08 EXCLUSIONS & RECONSTRUCTION / 禁止项与重建要求
[本页最容易发生的具体科学误读与禁止连接]。
不虚构数据、显著性、机制、引文或验证结果；不加装饰性科学对象。
保留所附参考的对象细度、分区层次与信息容量，图形以 path/rect/circle/line 等重建。
文字留独立锚点，最终逐项创建为 PPT 原生文本框；不能整页 SVG 插图。
不把真实照片/数据图重新想象生成；不要用空框和通用图标代替已知机制。
```

方括号是本规范的填写说明，实际提交时必须替换为本页内容。不适用的项用一句具体原因说明。提示词不能引用“同上”“按 skill”“见内容卡”来代替实际内容；生图工具不会自动读取这些文件。提到附图时必须实际传入，未提供的附图不能声称已提供。

八段固定的是信息组织，构图在第 05 段按页决定。不要把其他页的对象、否定词清单和全套参考图无差别复制到每页。图元描述充分即可，不设最低字数，也不堆砌同义风格词。

## 6．不同内容页的填写示例

以下均为教学任务前提，不是文献事实或实验结果。演示相同八段如何容纳不同构图；正式使用时以当前来源替换。

### 示例 A：机制页——离线知识与在线验证分区

给定前提 S1：拟研究系统先用历史任务特征与候选配置/误差训练性能估计器；当前任务特征与候选配置输入估计器，输出误差估计并排序；执行被选候选后获得样本外验证误差，拟用于下一轮更新，尚未验证收益。

```text
01 OUTPUT & MESSAGE / 输出与核心问题
16:9 中文科研汇报设计参考；受众为熟悉模型选择的研究者。
标题“历史经验与当前验证如何共同支持候选选择”；章节“研究方案”。
核心问题是两类信息在何时可用；本页只解释拟议信息流，不宣称性能提升。

02 EVIDENCE BOUNDARY / 来源与证据边界
按给定研究方案：历史任务特征、候选配置和误差训练估计器；当前特征与配置产生误差估计和排序。
执行被选候选后才取得样本外验证误差。下一轮更新是拟议机制，收益未验证。

03 ENTITIES & INTERNAL DETAIL / 对象与内部结构
历史档案画成任务记录栈，分别标出“任务特征”“候选配置”“历史误差”，不填虚构数值。
估计器内部算法未指定，保留标明“性能估计器”的黑箱，不擅自画成神经网络。
当前任务画有顺序的观测序列与特征向量；候选池画多个配置符号，另设被选配置。
误差估计输出用无数值字段和排序列表表达；执行、验证、下一轮更新是三个明确阶段。

04 RELATIONS / 科学连接
历史记录到训练，再到估计器版本：实线表示离线训练关系。
当前特征和候选配置分别进入估计器；估计误差进入排序；被选配置进入执行，再到验证。
验证输出到“下一轮更新”为带“拟议”标签的虚线；不得回到已完成的本轮排序。

05 COMPOSITION / 构图与阅读路径
采用上方离线、下方在线的双通道；离线约占内容区三分之一，在线为主视觉。
在线从左到右读，右端的更新回路经下缘指向下一轮估计器，避免穿过标签。
标题与章节在顶部；底部留一句“收益待验证”。上一页讲需求，本页解释时点，下一页安排验证。

06 QUANTITATIVE PANELS & LABELS / 图表与准确标签
无真实定量结果，不画性能对比柱图、精度或改善百分比。观测序列标“示意”。
准确标签：“离线训练”“当前任务特征”“候选配置”“误差估计”“排序”“执行”“样本外验证”“下一轮更新（拟议）”。
误差估计与已观测误差分开命名，无复杂公式。

07 VISUAL SYSTEM / 视觉系统
白底，深灰文字；历史信息用灰蓝，当前信息用青绿，拟议更新用少量紫红并加虚线和标签。
线条清楚、轻填色，当前选择流程最醒目，容器边界从属；直接标注对象并保留一个线型图例。
图元内部细节和文字在投影尺度可读；无附图。

08 EXCLUSIONS & RECONSTRUCTION / 禁止项与重建要求
不把误差估计当实测误差，不画当前未知验证结果提前进入排序，不暗示已证明收益。
不虚构估计器结构或数值；保留清晰的模块、连接端点和独立文字锚点以便 SVG 重建。
```

### 示例 B：比较页——并列机制，而非伪时间线

给定前提 S1：教学方法甲提取任务的趋势、季节性特征，用随机森林分类器中多棵树的投票输出一个候选标签。S2：教学方法乙将任务特征与候选配置映射到误差估计，再按估计排序，其内部估计器未指定。没有年代、实验数据或相互继承关系。

```text
01 OUTPUT & MESSAGE / 输出与核心问题
生成 16:9 中文科研比较页参考，标题“推荐标签与估计性能的决策对象不同”。
受众为方法讨论组；问题是两种教学方法分别输入什么、输出什么，不比较优劣。

02 EVIDENCE BOUNDARY / 来源与证据边界
方法甲按给定前提提取趋势、季节性特征，经随机森林的多树投票输出一个候选标签；方法乙接收任务特征与候选配置，输出误差估计并排序。
两者均为教学示意，无论文身份、发表年代或验证结论，不补造这些信息。

03 ENTITIES & INTERNAL DETAIL / 对象与内部结构
共同任务输入用时序示意与趋势、季节性特征向量表示。甲画多棵具有分支与叶节点的决策树，叶节点连接候选类别标记，再汇入投票节点，输出一个标签。
树群为结构示意，不表示实际树数，不填分裂阈值或票数；这部分内部结构说明分类器怎样工作。
乙另画候选配置集合进入“性能估计”黑箱，输出按候选对应的估计字段，再进入排序列表。
候选符号保持同一身份；乙的内部算法未指定，不擅自把黑箱画成另一片森林或神经网络。

04 RELATIONS / 科学连接
甲：时序到特征，再分别进入多棵决策树；类别输出汇入投票，再到候选标签。乙：特征与配置分别到性能估计，再到误差估计，再到排序。
方法间用对齐和共同输入标签比较，不画甲到乙的箭头；估计字段与候选逐项对应。

05 COMPOSITION / 构图与阅读路径
采用上下两个等权横向机制带，左对齐输入，右对齐最终输出；乙的中间区域适当加宽容纳估计与排序。
底部用括号归纳“决策输出不同”，不放优胜标记；阅读先甲后乙再比较。
相邻页若讲闭环，本页保留并列结构以突出比较职责，不追加反馈回路。

06 QUANTITATIVE PANELS & LABELS / 图表与准确标签
全部为机制示意，无性能曲线或柱图；估计字段不写数值，不用长短暗示真实误差。
准确标签：“教学方法甲”“教学方法乙”“任务特征”“趋势”“季节性”“候选配置”“随机森林分类”“投票”“候选标签”“性能估计”“误差估计”“排序”。
两个机制带各标“示意”，无公式。

07 VISUAL SYSTEM / 视觉系统
Nature figure 式白底、精准轮廓、留白分组；两种方法等权，避免颜色暗示乙更优。
任务输入统一灰蓝，候选统一青绿，输出用同一强调色加不同文字区分；箭头为细实线。
标签贴近对象，共同字段对齐，投影可读；无附图。

08 EXCLUSIONS & RECONSTRUCTION / 禁止项与重建要求
不暗示方法乙发表更晚、继承方法甲或已证明更准，不编造论文名、年份、树阈值、票数或乙的内部算法结构。
不将不同输入涂成同一种来源；保留可重建几何与独立文字锚点，不以空白卡片替代输入输出。
```

### 定量页的专门改写

若页面需要“消融结果 + 机制解释”，第 03、05 段仍可具体描述受控模块与构图，但第 06 段必须逐项指定定量图源。没有数据时写：

> 右侧预留真实消融图区域，列明横轴为已定义的实验条件、纵轴为待测指标及其方向；区域内只标“待填真实结果”，不合成柱高、散点、曲线、误差条、排名或显著性。左侧以机制示意表达唯一变化因素，标题写“消融设计”而非“消融证明有效”。

已有数据时先用确定性绘图工具生成真实图。若作为附图输入，明确只能参考其位置、尺寸与样式，最终成稿放回真实图源，不采用生图重绘的数值形状。残差、ACF、频谱等相互依赖的小图也从同一条数据或同一构造序列计算，不能让生图模型分别编造。

## 7．两次检查，修正后才锁定参考

在 `checks/NN-prompt-review.md` 保存两阶段记录，逐条写“通过 / 待修正 / 不适用：原因”及简短依据。不能只给总分或预填全部通过。

**提交前，检查真实提交文本及附件：**

1. 八段已展开，没有未替换的填写说明、对工具不可见的“见文件”或缺失附图。
2. 核心问题与结论强度匹配，关键机制、结论均能回到内容卡的来源；未知没有被补画为事实。
3. 对象清单逐项出现在提示词，有输入输出及来源支持的内部细节；黑箱边界明确。
4. 关系清单逐条落地：起止、传递物、方向、阶段及证据类别无冲突，无比较变因果、未来信息提前使用。
5. 图表的变量、单位、示意/真实/预留身份清楚；不要求图像模型制造定量证据。
6. 构图和面板职责支持本页问题，阅读路径明确，密度可读；与邻页相同结构有科学或讲述理由。
7. 标签、语义配色、线型、重点和附图用途明确，适合后续 SVG 与独立文字重建。

**返回后，实际查看整图与关键局部：**

1. 对照对象清单：主对象、必要内部结构、辅助图、状态与标签是否完整且对应。
2. 对照关系清单：逐条看箭头方向、端点、线型和阶段；检查生成器是否自行添加暗示。
3. 检查数值、曲线、公式和结论；未经来源支持的新增内容必须移除。真实数据预留区不能以生成曲线充当结果。
4. 对照实际正例检查主次层级、布局、尺度、图例和投影可读性；同一模型/状态的颜色和符号一致。按质量规范查看整页与放大局部，检查糊边、碎块、断线、假细节和标签融合，记录具体位置。
5. 标记需在独立文字层修正的错字；缺对象、错关系或结构不清不能只靠替换文字掩盖。

有实质科学错误、缺关键对象、风格/信息密度明显偏离正例、图形普遍模糊或布局无法重建时，先修正对应提示词段落并定向编辑/重生该页；未达标图不计入有效覆盖。纯文字渲染错误可保留图形，但记录准确文字与锚点。修复后才锁定参考并进入测量重建；不能将科学错误作为“一比一还原”目标。已达标原图在重建中失真时修复重建，不重抽原图。重复生成仍未解决时，记录未完成问题，不声称已通过，可继续其他页面。

## 8．保存与现有清单衔接

每张新增或重新生成的内容参考保存内容卡、最终提示词、实际返回图和检查记录；修改提示词时保留对应候选，确保最终选择可追溯。执行模型、推理设置与生图工具/模型只记录实际可见值；未披露写“未披露”，不能推测。换 Sol/Astra 时复用已核对内容卡与语义色表，不重新发明来源事实。
