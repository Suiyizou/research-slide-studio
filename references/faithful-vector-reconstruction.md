# 构图保真与矢量重建

## 当前默认：尽量复刻，允许简化细纹理

先对照参考，记录标题、主内容区、留白、连接路径和装饰的位置比例，再重建。局部好看的插画不能擅自放大成为全页主题；例如右下角的小山形仍应保留右下角的面积和作用。

优先级：科学语义正确 → 主构图与比例 → 信息密度和字体层级 → 几何细节 → 纹理。允许为阅读略调字号，不能借此重排成完全不同的构图。可以使用中文解释与英文术语、标题，不必逐句双语重复。

## 真正的矢量化

- 文字保持独立可编辑文本，默认放在后续 PPT 文字层；线条是线条、贝塞尔曲线或自由路径；柱条、矩阵、图标和山形轮廓用独立形状重建。原生贝塞尔曲线可保留控制点；不以碎直线替代本可平滑表达的弧线。
- SVG 应实际包含 path、rect、circle 等图元。默认导出纯图形 SVG，标题、说明、公式和标签另存文字坐标层；仅在用户需要完整含文字 SVG 时使用 text 图元。把 PNG 包装进 SVG、把整图分块后粘贴，都不属于本工作流的矢量重建。
- 不要求所有视觉纹理都成为原生对象。仅在用户同意并且确有必要时局部使用透明插画；说明该层可移动缩放，但图内元素不能逐项编辑。
- 自动描摹可能产生大量无语义节点。优先按对象结构重绘，再人工对照，而不是追求节点数量。
- 不承诺从位图自动恢复完全相同的字体、阴影和编辑结构；以实际渲染对照展示接近程度。

## 对象级 SVG 精细重建（复刻任务优先）

用户强调按原图复刻时，将纯图形 SVG 作为精细几何图源，PPT 作为独立文字编辑和动画载体；按 [省预算流程](graphics-first-budget-workflow.md) 复用已有组件。此选择不强制用于无参考图的新稿，也不改变用户要求的交付格式。

### 测量与重建

- 采用与原图宽高比例一致的 `viewBox`，记录关键对象的边界框、锚点、层级与连接关系。先锁定主构图，不凭目测重新排列、扩大装饰或改变信息密度。
- 按对象建立有含义的分组及稳定 ID，例如 `memory_store`、`residual_trace`、`feedback_arrow`。每个图标、曲线、矩阵和预算条独立可选；文字区域与坐标独立保存，稍后编辑；不要只按页面区域合并成几块无法编辑的图形。
- 使用实际的 `path`、`rect`、`circle`、`line` 等图元。默认不在图形阶段描摹字形或调整最终措辞；只有完整含文字 SVG 模式才使用 `text`。曲线按原图轨迹和控制点重建，保留线宽、虚实、箭头端点、色彩与透明度层级。科学数据曲线由真实数据驱动；纯示意曲线明确标注，不把像素描绘当作原始数据恢复。
- 重建原图中承载含义的图标、坐标轴、图例、局部小图、预算刻度和状态标记。不能将这些细节替换成反复使用的通用折线、矩阵或方框。复杂纹理可以简化，简化不得移除科学含义。
- 自动描摹仅作为轮廓提取的辅助。对结果清理节点、恢复对象分组；图内文字另存标签层，不自动描摹成字形路径；未经这些处理，不把大量无含义路径称作对象级重建。PNG 包装进 SVG、规则裁切再粘贴均不满足此要求。

### 进入 PowerPoint

- 保留纯图形 SVG 图源及独立文字坐标层。先测试实际 Office 对 SVG 的渲染和转换，不能仅凭导入成功便认定图内文字和路径可编辑。
- 需在 PPT 改字的标题、标签、公式和数据表保持或重建为原生文字、公式及表格；若 SVG 转换将文字轮廓化，替换该文字层，避免重复显示。复杂装饰可保留独立 SVG 层，但不能宣称其内部已转成原生 PPT 对象。
- 按讲解阶段拆成有含义的对象组，连接线与对应模块同步。使用 MCP 或当前环境的文档接口处理对象位置、分组、文字和动画；不强制所有精细路径逐个通过 MCP 绘制。

### 复刻验收

- 先做一张具有代表性的关键图，对照原图验证对象结构、几何与 Office 转换，再推广到其他必要关键图，避免批量复制未经验证的简化策略。
- 以相同画幅进行原图与 SVG 渲染、PPT 实际渲染的并排和半透明叠加对照。检查位置比例、曲线轨迹、线宽、图例、文字换行和细节；对关键局部放大检查。对象计数、格式转换成功和文件结构检查不能代替这些观察。
- 科学错误必须纠正，并记录纠正与构图重建的区别。保留 SVG 图源、对象清单和对照图，明确残留差异。未经测量和审阅，不编造“90% 相似”等数值。

## 动画与对照检查

每页规划 initial、steps、keep_visible、reason。标题与图例通常初始可见；同一问题的图、标签和入线同阶段出现。对照图同时出现对应基线，状态更新与入线一起出现，避免悬空箭头。

先检查完整静态效果，再检查初始、中间、最终状态。播放检查可用 PowerPoint 原生视频副本：副本将点击触发改为自动，正式文件保留点击触发。明确这属于视频预演，不冒称实际鼠标逐次点击验证。

本次模板重点：第 2 页阶梯问题图，山形保持右下角；第 6 页上下两条特征泳道；第 19 页恢复原生贡献—证据结构。第 2、6 页无图片切片，文本、曲线、矩阵和形状均为原生对象。
